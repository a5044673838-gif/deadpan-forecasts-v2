A deadpan weather forecast for Mizzleford, a city that does not exist. Sideways rain, gusts of wet gravel, a high of 11 degrees, and — as ever — no apology from the sky. The program is deterministic, uses only the Python standard library, and writes a single line to the output file.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
